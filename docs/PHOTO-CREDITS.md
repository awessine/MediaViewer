# Фотографии на скриншотах

Для документации использована отдельная демонстрационная коллекция из 11 фотографий с Wikimedia Commons. Она не связана с личной медиатекой пользователя. Названия файлов сокращены для примеров, теги и правила созданы специально для скриншотов.

В репозиторий включены только снимки работающего интерфейса из `docs/screenshots/`. Скачанные исходные фотографии, данные браузера и демонстрационная разметка в репозиторий не добавлены и не поставляются с приложением.

## Лицензии и изменения

Фотографии уменьшены до демонстрационного разрешения. Приложение масштабирует их в карточках и подробном просмотре; часть изображения может находиться за границами видимой области. Снимки интерфейса сохранены в JPEG. Ретушь фотографий и дорисовка интерфейса не выполнялись.

Скриншоты в `docs/screenshots/`, подготовленные для проекта MediaViewer, распространяются по [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). При их повторном использовании указывайте проект [MediaViewer](https://github.com/awessine/MediaViewer), авторов фотографий из таблицы, ссылки на источники и лицензии, а также собственные изменения.

Исходные фотографии сохраняют свои лицензии, перечисленные выше. Лицензия MIT на исходный код приложения и ISC на значки Lucide остаются без изменений и не заменяют лицензии фотографий.
