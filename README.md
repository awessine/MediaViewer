# MediaViewer

Локальный просмотрщик фото, видео, GIF и аудио в одной медиатеке. Открывает папку смешанных медиафайлов, показывает их плиткой и позволяет переходить к подробному просмотру, размечать коллекцию тегами и объединять файлы в многостраничные группы.

Приложение работает в браузере без сервера, регистрации, сборки и подключения к интернету. Интерфейс на русском языке, темная тема с розовым акцентом.

## Быстрый запуск

1. Скачайте репозиторий через **Code > Download ZIP** и распакуйте архив или клонируйте его:

   ```bash
   git clone https://github.com/awessine/MediaViewer.git
   ```

2. Откройте [app/MediaPlaylistViewer.html](app/MediaPlaylistViewer.html) в актуальном Chrome или Edge. В Windows можно запустить [app/Start-MediaPlaylistViewer.cmd](app/Start-MediaPlaylistViewer.cmd): он откроет приложение в браузере по умолчанию.
3. Нажмите **Открыть папку** или **Добавить файлы**. Для запоминания папки и операций с диском разрешите доступ, когда браузер его запросит.

Устанавливать Node.js, Python, дополнительные кодеки или зависимости проекта не требуется. В браузере по умолчанию, отличном от Chrome или Edge, некоторые функции доступа к файловой системе могут быть недоступны.

## Возможности

### Открытие коллекции

- Фото, видео, GIF и аудио отображаются в одной коллекции без переключения между отдельными просмотрщиками.
- Выбор папки с возможностью включить или отключить подпапки.
- Добавление нескольких файлов к уже открытой коллекции без ее очистки.
- Перетаскивание файлов и папок в область просмотра; доступность перетаскивания папок зависит от браузера.
- Запоминание последней выбранной папки. При следующем запуске она открывается снова, если браузер сохранил разрешение; иначе приложение попросит повторно разрешить доступ.
- Индикатор загрузки с количеством обработанных файлов или процентами для операций, у которых известен общий объем работы.

### Плитка

- Плиточная раскладка по колонкам с учетом пропорций изображений.
- Постепенное добавление карточек и ленивая загрузка медиаконтента вблизи видимой области.
- Ползунок размера миниатюр; выбранный размер сохраняется локально.
- Случайный порядок включен по умолчанию. Порядок не пересоздается при прокрутке или назначении тегов.
- Сортировка по имени, дате изменения, типу или размеру файла, а также случайная сортировка.
- Поиск по имени файла и пути папки, с учетом нескольких слов в запросе.
- Отбор по одному или нескольким тегам: файл должен соответствовать всем выбранным тегам. Фильтры можно снять по отдельности или сбросить вместе.
- Отдельный фильтр **Многостраничные** для групп с несколькими файлами.
- Отображение названия, типа, размера и назначенных тегов на карточке.
- Добавление тегов через кнопку `+` рядом с текущими тегами карточки.
- Выбор нескольких элементов с контекстной панелью для группировки, разгруппировки и группового назначения тегов.
- Воспроизведение видео прямо в плитке. Одновременно проигрывается только одно видео; щелчок по нему переключает воспроизведение и паузу. Кнопка запуска скрывается во время воспроизведения.
- Щелчок по изображению или информационной панели карточки открывает подробный просмотр. Для видео щелчок по самой видеоповерхности управляет воспроизведением, а по панели с названием открывает подробный просмотр.

### Подробный просмотр

- Изображение открывается поверх затемненной плитки, а не на отдельной странице.
- Файл автоматически вписывается в доступную область при открытии, включая вертикальные изображения.
- Размер окна просмотра подстраивается под медиаконтент.
- Стрелки переключения расположены слева и справа от файла, по центру его высоты.
- Переключение отдельных файлов следует текущему порядку плитки, включая ее случайный порядок.
- Название и назначенные теги находятся под медиаконтентом; остальные теги доступны через `+`.
- Масштаб от 25% до 500%, кнопки увеличения, уменьшения и сброса, а также масштабирование колесом мыши с `Ctrl`.
- Режимы **Вписать**, **Заполнить** и **Оригинал**, с прокруткой увеличенного содержимого.
- Воспроизведение и пауза видео и аудио; для видео доступен повтор. Щелчок по видео переключает воспроизведение и паузу.
- Полноэкранный режим, в котором сохраняется доступ к управлению и выбору тегов.
- Возврат в плитку кнопкой назад, щелчком вне окна просмотра или клавишей `Esc`. Позиция прокрутки сохраняется в текущем сеансе.

### Теги

- Создание, назначение, снятие и удаление собственных тегов.
- Новый тег сразу назначается текущему файлу, папке или выбранным элементам, в зависимости от контекста.
- Поиск тегов в отдельном окне выбора.
- Изменения в окне выбора сначала накапливаются и применяются при его закрытии, в том числе кнопкой **Готово**.
- Групповое назначение тегов выбранным элементам плитки.
- Счетчик количества файлов с каждым тегом.
- Сортировка тегов по количеству файлов во всех списках тегов.
- Автоматические теги расширений, например `.jpg`, `.gif` или `.mp4`.
- Локальное сохранение разметки и автоматическое восстановление при повторном открытии файлов.

Для отдельных файлов разметка привязана к имени файла. Для файлов подпапки используются общие теги, привязанные к относительному пути папки. Поэтому отдельные файлы с одинаковыми именами могут разделять разметку; разные подпапки имеют независимые общие теги. Счетчики показывают количество файлов, а не количество карточек: многостраничная группа может увеличивать счетчик на несколько файлов.

### Автотеги

- Редактор правил автоматического назначения тегов по имени файла, названиям папок или обоим источникам.
- Создание начальных правил по собственным тегам через **По моим тегам**.
- Несколько ключевых слов и синонимов для одного правила.
- Совпадение по словам и фразам, по части текста или по точному нормализованному имени.
- Нормализация регистра, разделителей и написания `е`/`ё` при сопоставлении.
- Включение и отключение отдельных правил, добавление и удаление правил.
- Обработка всей коллекции, выбранных элементов или текущего файла.
- Предпросмотр найденных совпадений и новых тегов до применения.
- Прогресс обработки и возможность ее остановить.
- Применение без удаления существующих ручных тегов и отмена последнего применения автотегов.
- Автоматическая обработка новых добавленных файлов, которую можно отключить.
- Сохранение правил в браузере. Публичная версия не содержит предустановленных личных тегов или словаря персональных соответствий.

Автотеги работают по текстовым правилам. Распознавания содержимого изображения нейросетью нет.

### Группы и подпапки

- Объединение выбранных файлов в многостраничный элемент плитки и обратная разгруппировка.
- Автоматическая группировка файлов из подпапок выбранного каталога. Файлы в корне остаются отдельными элементами.
- Одна карточка на группу; обложкой служит первый файл в естественном порядке имен.
- Числовые имена упорядочиваются как `1, 2, 3, ..., 10, 11`, а не `1, 10, 11, 2`.
- Общие теги на все файлы одной подпапки. При переходе со старой разметки теги ее страниц объединяются.
- Кружочки текущей страницы и поле номера страницы для быстрого перехода, в том числе в больших группах.
- В подробном просмотре стрелки переключают страницы внутри выбранной группы и не перескакивают случайно на соседний элемент. Чтобы открыть другую группу, вернитесь в плитку.
- Разгруппировка автоматически созданной группы запоминается локально.

Общие теги относятся именно к папкам. Произвольная ручная группа из файлов разных папок не превращает их разметку в одну общую запись.

### Операции с файлами

- Переименование текущего файла на диске, с проверкой имени и конфликтов.
- Удаление текущего файла с диска после подтверждения.
- Сохранение связей тегов и групп при переименовании через приложение.
- Обновление обложки и состава группы после удаления ее страницы.
- Удаление файла только из текущей коллекции клавишей `Delete`, без удаления с диска.

**Важно:** удаление с диска выполняется без корзины Windows. Оно не равнозначно удалению из коллекции и не имеет встроенной отмены.

Для переименования и удаления браузеру нужен доступ на запись к папке. Если прямое переименование недоступно, приложение потоково создает файл с новым именем и удаляет исходник только после успешного завершения записи. Для больших видео это может занимать время. Эти операции меняют настоящие файлы, поэтому перед работой с важной коллекцией рекомендуется резервная копия.

## Форматы

Приложение распознает следующие расширения:

| Категория | Расширения |
| --- | --- |
| Изображения и анимации | `jpg`, `jpeg`, `png`, `gif`, `bmp`, `webp`, `avif`, `svg`, `ico` |
| Видео | `mp4`, `webm`, `ogv`, `ogg`, `mov`, `m4v`, `mkv`, `avi`, `wmv` |
| Аудио | `mp3`, `wav`, `ogg`, `oga`, `m4a`, `aac`, `flac`, `opus` |

Это список распознаваемых расширений, а не гарантия декодирования любого файла. Реальное воспроизведение зависит от браузера, контейнера и кодека. Приложение не устанавливает кодеки и не конвертирует неподдерживаемые файлы. Расширение `ogg` классифицируется как аудио; для видео Ogg используйте `ogv`.

## Управление с клавиатуры

| Клавиша | Действие |
| --- | --- |
| `←` / `→` | Предыдущий или следующий файл либо страница группы |
| `Пробел` | Воспроизведение или пауза |
| `Esc` | Закрытие активного окна или возврат из подробного просмотра |
| `F` | Переключение полноэкранного режима |
| `F2` | Переименование файла в подробном просмотре |
| `+` / `-` | Увеличение или уменьшение масштаба |
| `Ctrl` + колесо мыши | Изменение масштаба в подробном просмотре |
| `Delete` | Удаление текущего файла из коллекции, не с диска |
| `Tab` / `Shift` + `Tab` | Переход между доступными элементами управления |

Команды просмотра не перехватываются во время ввода текста. Окна выбора тегов и операций удерживают клавиатурный фокус внутри окна.

## Хранение данных и приватность

- Медиафайлы читаются локально и не отправляются на сервер приложением.
- Теги, группы, правила автотегов, история последнего применения и размер миниатюр хранятся в `localStorage` браузера.
- Доступ к последней папке запоминается в `IndexedDB`; браузер управляет разрешениями на ее чтение и запись.
- Теги не записываются в EXIF, XMP или другие метаданные исходных файлов.
- Разметка не синхронизируется между браузерами и устройствами. Очистка данных сайта или смена профиля браузера может привести к ее потере.
- Случайный порядок и позиция плитки сохраняются во время работы приложения, но полное восстановление сеанса после перезапуска пока не реализовано.
- В репозитории нет личных тегов, разметки файлов, пользовательских правил, сохраненных папок, медиафайлов или скриншотов коллекции. `.gitignore` разрешает добавление только перечисленных публичных файлов проекта.

Публичная копия HTML не переносит пользовательские данные из другой локальной копии. Экспорт и импорт разметки пока не реализованы.

## Ограничения

- Запоминание папки и изменение файлов требуют поддержки File System Access API и разрешений браузера. Подробнее: [документация Chrome](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access).
- Если нужный API недоступен, папка открывается через обычный выбор файлов, без гарантии восстановления доступа при следующем запуске.
- Ленивая загрузка уменьшает число одновременно загруженных медиафайлов, но карточки накапливаются при прокрутке. Постоянный кэш миниатюр и полная виртуализация плитки пока не реализованы.
- Переименование вне приложения не отслеживается автоматически. Для отдельного файла с новым именем прежняя разметка может не восстановиться.
- Приложение не восстанавливает оригинальное имя переименованного файла и не читает метаданные для такой задачи.
- Избранное, рейтинги, поиск дубликатов, сравнение изображений, пакетное переименование и перемещение пока не реализованы.
